# Use the ChatGPT and Codex adapters

The MCP server exposes read-only discovery, list, read, and checkpoint operations. Choose the source you have: a configured ChatGPT local store, an installed Codex app server, or both.

1. [Install and configure the server](installation-and-configuration.md) in a local checkout and your MCP host.
2. [Acquire sessions](acquiring-sessions.md) from either adapter and stage them in a receiving Knowledge Islands repository.
3. [Troubleshoot discovery and empty results](troubleshooting.md) before changing paths or configuration.
