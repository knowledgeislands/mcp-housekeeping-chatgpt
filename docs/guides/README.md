# ChatGPT and Codex housekeeping guides

These guides cover installation, read-only acquisition, troubleshooting, and local development for the combined ChatGPT and Codex MCP server. ChatGPT uses an optional opaque local store; Codex uses the installed `codex app-server` and a selected physical repository.

- [User guides](user/README.md) explain configuration, acquisition, and common empty or failing results.
- [Developer guides](developer/README.md) explain fixture-based maintenance and the separate exported Codex library boundary.
